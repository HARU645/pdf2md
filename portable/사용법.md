# pdf2md — USB에서 바로 쓰는 판

PDF나 저장한 웹페이지를 **AI가 읽기 좋은 마크다운**으로 바꿉니다.
설치가 필요 없습니다. 이 폴더 하나면 끝입니다.

## 쓰는 법

`실행.bat` 을 더블클릭하세요. 검은 창이 뜨고, 잠시 뒤 브라우저가 열립니다.

- **처음 켤 때는 느립니다.** USB에서 400MB를 읽어야 해서, USB 2.0이면 1분쯤
  걸릴 수 있습니다. 두 번째부터는 훨씬 빠릅니다.
- **끄려면 검은 창을 닫으세요.** 브라우저 탭만 닫으면 앱은 계속 돌고 있습니다.

## 이 폴더에 뭐가 들었나

```
실행.bat      더블클릭하는 파일
python\       파이썬 본체 (설치 대신 들고 다니는 것)
pdf2md\       변환하는 코드
visk\         VISK 원본과 변환 결과
   html\         저장한 웹페이지 (변환은 이쪽을 먼저 씁니다)
   pdf\          인쇄한 PDF (웹페이지가 없을 때 쓰는 대체 경로)
   markdown\     변환 결과
```

앱을 켜면 `visk` 폴더를 알아서 찾습니다. 드라이브 문자가 `E:`든 `F:`든
상관없습니다.

## 자주 걸리는 것들

**"Windows가 PC를 보호했습니다" 창이 뜬다**
`추가 정보` → `실행`을 누르세요. 인터넷에서 받은 파일에 붙는 경고입니다.

**검은 창이 바로 닫힌다**
`python` 폴더가 같이 복사되었는지 확인하세요. 폴더 하나라도 빠지면 안 됩니다.

**회사나 학교 컴퓨터에서 안 된다**
관리자가 실행 파일을 막아둔 경우입니다. 이건 우회하지 마시고 개인 컴퓨터를
쓰세요.

## 바깥에서는 접속할 수 없습니다

이 판은 **켠 컴퓨터 안에서만** 열립니다 (`127.0.0.1`). 같은 와이파이에 있는
다른 사람도 들어올 수 없습니다. 그래서 비밀번호도 묻지 않습니다.

## 새 절을 추가하려면

1. 브라우저에서 VISK 페이지를 열고 `Ctrl+S` → **웹페이지, 전체**로 저장
2. 저장한 `.html` 파일을 `visk\html\` 에 넣기
3. `실행.bat` → **변환하기** → **이 컴퓨터의 폴더에 저장**

PDF보다 저장한 웹페이지가 정확합니다. 표와 주석 구조가 그대로 남아 있어서
좌표를 보고 되짚을 필요가 없습니다.
